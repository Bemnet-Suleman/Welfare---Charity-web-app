✨ Charity Welfare Web App
📖 Project Overview
The Charity Welfare Web App is designed to support welfare and charity initiatives. It connects donors, volunteers, and beneficiaries, making it easier to contribute resources, track impact, and promote solidarity.

🚀 Features
🧾 Donation System – Secure and transparent contributions

👥 Volunteer Management – Sign‑up and scheduling for events

📊 Impact Dashboard – Track funds, projects, and beneficiaries

📢 Campaigns & Events – Share causes and upcoming charity drives

🔒 Authentication – Safe login for users and admins

🛠️ Tech Stack
Frontend: React + TailwindCSS

Backend: Node.js / Express

Database: MongoDB

Deployment: Vercel

📂 Project Structure
Code
/client   → frontend code
/server   → backend code
/public   → static assets
⚡ Getting Started
Clone the repo:

bash
git clone https://github.com/your-username/Welfare---Charity-web-app.git
Navigate to the project:

bash
cd Welfare---Charity-web-app
Install dependencies:

bash
npm install
Run locally:

bash
npm run dev
