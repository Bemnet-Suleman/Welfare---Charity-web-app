BN-01 (merged)

| Field | Value |
|---|---|
| Use Case ID | BN-01 |
| Use Case Name | Submit Aid Request and Upload Verification Documents |
| Primary Actor(s) | Beneficiary |
| Secondary Actor(s) | Web App UI; File Storage |
| Description | Beneficiary submits an aid request with required details and uploads verification documents (IDs, photos, supporting files); the request and documents are validated, stored, and routed into the review workflow. |
| Trigger | Beneficiary selects "Submit Aid Request" or chooses to attach verification documents to an existing request. |
| Preconditions | Beneficiary authenticated; request form available; file storage service operational; allowed file types/sizes configured. |
| Postconditions | Aid request recorded; verification documents stored and linked to the request; request enters review/approval workflow. |
| Basic Flow | 1. Beneficiary opens the aid request form. 2. Beneficiary fills required fields and optionally saves a draft. 3. Beneficiary attaches verification documents (one or more files). 4. System validates form fields and file types/sizes; uploads files to File Storage; links files to the request. 5. System saves the request as "submitted" and notifies admins/queue for review. |
| Alternative Flows | - Save draft and upload documents later. - Upload additional or replacement documents after initial submission. - Submit without documents if policy allows, triggering a "request more info" path. |
| Exception Flows | - File upload failure → show error, allow retry, and queue upload. - Validation errors on form fields → highlight errors and prevent submission. - File type/size violation → reject file and prompt user to provide acceptable files. |
| Business Rules | - Required fields must be completed before final submission. - Only allowed file types and size limits accepted. - Sensitive personal data must be handled per privacy policy and access controls. |
| Special Requirements | - Files encrypted at rest; virus/malware scanning on upload. - Audit trail linking documents to requests and submitter. - Secure transport (TLS) for uploads. |
| Assumptions | Beneficiary can provide required documents; File Storage and notification systems are available. |
| Frequency of Use | Low–Medium (per aid request)
